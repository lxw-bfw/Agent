# Quickstart

## 安装后第一条怎么发

如果你想显式调用，直接输入：

```text
/paid-ai-writing-sop
```

或者用自然语言触发：

```text
用 paid-ai-writing-sop 处理当前任务
```

## 改写示例

```text
用 paid-ai-writing-sop 改写当前工作区的《xxx.md》。
先判断文章类型，再输出任务卡、新结构和正式成稿。
```

## 从 0 撰写示例

```text
用 paid-ai-writing-sop 从 0 写一篇关于 Claude Code Skills 的付费级教程。
目标读者是刚接触 Agent Skills 的开发者，平台是公众号。
```

说明：

- Skill 会先发默认调研模板确认话术。
- 用户确认前，不会进入正式调研或全文写作。

## 结构优先示例

```text
按 paid-ai-writing-sop 先只输出结构，不写全文。主题是 Agent Skills 与 Cursor Rules 的区别。
```

这种场景会走相同分流逻辑，但在结构阶段停止。
