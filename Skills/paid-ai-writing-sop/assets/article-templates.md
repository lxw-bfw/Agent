# 正文模板库

这份文件是 `paid-ai-writing-sop` 的内置正文骨架库。

用法固定如下：

1. 先按 `references/article-types.md` 判断文章类型
2. 再从下面三套骨架里选一套作为正文主结构
3. 结合任务卡、调研结论、事实核验表和风格策略填充内容
4. 成稿前统一补核验日期、误区纠偏、踩坑提醒、适用边界、资料来源清单

不要跳过类型判断，直接临场拼结构。

## 一、推荐型正文骨架

### 适用场景

- 工具推荐
- 仓库推荐
- 插件推荐
- 模型推荐
- 平台推荐
- 方案对比

### 核心目标

让读者看完知道：

- 为什么推荐这些，而不是别的
- 每一个推荐项到底适合谁
- 第一次应该先从哪一个开始
- 哪些适合单独用，哪些必须组合用

## 二、教程型正文骨架

### 适用场景

- 安装教程
- 搭建教程
- 配置教程
- 工作流教程
- 工具接入教程
- 从 0 到 1 上手型文章

### 核心目标

让读者看完能：

- 知道先做什么
- 知道每一步做完长什么样
- 知道最容易失败在哪
- 知道如果只做最小闭环，应该怎么做

### 分层提醒

如果当前任务属于“从 0 撰写 + 教程型”，正文结构必须跟受众层级联动：

- `1 / 2`：优先“完整案例 -> 拆术语 -> 第二个完整案例”

## 四、三类模板怎么快速选

### 看到下面这些关键词，优先选推荐型

- 推荐
- 盘点
- 值得装
- 值得学
- 对比
- 选哪个

### 看到下面这些关键词，优先选教程型

- 安装
- 配置
- 搭建
- 上手
- 跑通
- 实操

### 看到下面这些关键词，优先选方法论型

- 为什么
- 怎么判断
- 最佳实践
- 框架
- 原理
- Prompt 写法

## 五、三个模板的通用补丁

无论你用哪一套模板，成稿前都应该补这几块：

### 1. 核验日期

```md
> 资料核验日期：YYYY-MM-DD
```

### 2. 第一条可直接复制内容

- 推荐型：第一条 Prompt
- 教程型：第一条命令 / 配置
- 方法论型：第一条模板

### 3. 误区纠偏

至少 3 条。

### 4. 踩坑提醒

至少 3 条。

### 5. 适用边界

一定要写：

- 适合谁
- 不适合谁
