# 使用指令骨架

这份文件给人类用户或外层调用者快速复用。

## 一、标准完整版

```md
用 `paid-ai-writing-sop` 处理当前任务。

要求：
1. 先判断这次是“改写已有原稿”还是“从0撰写新稿”
2. 如果我没有明确说模式，而且当前信息不足，请先问我
3. 再判断这篇文章属于推荐型、教程型，还是方法论型
4. 再按对应流程查官方一手资料和高质量第三方资料
5. 如果是从0撰写模式，默认优先做调研，不要直接开写
6. 先输出任务卡、风格提取表和新的文章结构
7. 再从对应正文骨架进入正式成稿
8. 成稿必须补核验日期、误区纠偏、踩坑提醒、适用边界、资料来源清单
```

## 二、快速处理版

```md
用 `paid-ai-writing-sop` 处理当前任务，先判断这次是改写还是从0撰写，再自动选择最适合的文章类型，直接输出付费级成稿。不要只润色，要补结构、补判断、补边界。
```

## 三、先出结构版

```md
用 `paid-ai-writing-sop` 处理当前任务，但先只输出模式判断、任务卡、风格提取表和新的文章结构，暂时不要写全文。
```

## 四、直接套模板版

```md
这次任务属于[改写已有原稿/从0撰写新稿]，文章类型属于[推荐型/教程型/方法论型]。请按 `paid-ai-writing-sop` 完成资料核验后，直接使用对应正文骨架输出成稿。
```

## 五、模式不明确时的标准问法

```text
你这次是要我基于已有原稿改写，还是根据主题从 0 撰写？
```

## 六、从 0 模式的标准确认话术

进入从 0 撰写模式后，优先使用：

- `references/research-confirmation.md`

由它负责默认调研模板确认与教程型受众追加确认。
