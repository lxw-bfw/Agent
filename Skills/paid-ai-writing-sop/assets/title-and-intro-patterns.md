# 标题与开头模板库

这份文件用于补强标题方向、导语开场和第一屏抓力。

可以复用结构，不要机械套字面内容。

## 一、工具推荐型标题模板

- `我最近反复在用的 X 个 AI 工具，不是因为新，而是因为真的省事`
- `这 X 个 AI Skills 我更建议你先装这几个，原因不是你想的那样`
- `别再只看热度了，这才是 X 类工具真正值得装的标准`
- `如果你想把 X 跑起来，这几类工具比“万能神器”更重要`

## 二、操作教程型标题模板

- `完整教程：从 0 到 1 搭好一个 X 工作流`
- `X 实操指南：真正把它跑通，你只需要先搞定这几步`
- `很多人卡在 X，不是不会点按钮，而是前面少了这层设置`
- `把 X 做成可复用流程，不是多加功能，而是先把骨架搭对`

## 三、Prompt / 方法论标题模板

- `Prompt 不是越长越好，真正决定效果的是这几个部分`
- `为什么同一个模型，有人越用越强，有人越用越乱`
- `如果你想让 X 更稳定，先别急着加技巧，先改这层结构`
- `把 X 用好，不靠玄学，靠这套最小判断框架`

## 四、推荐型开头模板

```md
先说结论：这篇不是普通的工具盘点，而是按“真正能装进工作流里”的标准来筛的。

很多这类文章的问题，不是工具不对，而是推荐逻辑有问题。它们只告诉你“这个很火”，但不告诉你“它到底适合谁、怎么装进自己的流程、什么时候根本不该用”。

所以这篇我准备换个写法：先把筛选标准讲清楚，再逐个展开每个工具到底值不值得你装。
```

## 五、教程型开头模板

```md
如果你只是想“试一下”X，网上大多数文章已经够了。

但如果你的目标是把它真正跑通，而且以后还能反复复用，那你缺的通常不是一个按钮教程，而是一套更稳的理解顺序：先准备什么，先验证什么，哪一步最容易翻车，做对之后长什么样。

这篇就按这个顺序来讲。
```

## 六、纠偏型开头模板

```md
先纠正一个很常见的误解：

很多人以为 X 的关键在 A，但如果你真的上手做过几轮，就会发现真正决定结果的其实是 B。

A 当然重要，但它更像表层操作。B 才是你能不能稳定做成、能不能把这套方法复用下去的分水岭。
```

## 七、使用提醒

- 推荐型优先强调筛选标准、适合谁和学习顺序
- 教程型优先强调结果、最小闭环和最容易翻车的地方
- 方法论型优先强调误解、判断框架和边界
- 标题与开头要服务于正文主结构，不要只追求抓眼球
