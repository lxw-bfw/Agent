# 从 0 模式的标准确认话术

当任务属于“从 0 撰写模式”时，在正式调研前必须先发送下面这段原话：

```text
我会按照 paid-ai-writing-sop 内置的默认调研输出模板来完成调研。

如果您有自己的标准调研输出模板，可以在下面的对话中提供给我，我会按照你的调研模板来。

如果没有的话，你可以发送指令“没问题，开始工作吧”，在接下来的从0撰写文章的工作中，我将使用 paid-ai-writing-sop 内置的默认调研输出模板继续调研。
```

## 行为契约

只有在下面两种情况下，才进入正式调研：

1. 用户提供了自己的调研模板
2. 用户明确回复“没问题，开始工作吧”或等效确认

如果用户没有确认，就停在这里，不要越过这一步。

## 教程型任务的追加确认

如果当前任务同时满足下面两个条件：

1. 属于“从 0 撰写模式”
2. 文章类型属于“教程型”

则在发送完上面的标准确认话术后，还要检查教程受众层级是否明确。

如果不明确，必须追加下面这段确认话术：

```text
在开始调研前，我还需要确认这篇教程主要写给哪类读者：

1. 完全零基础：几乎没接触过这个主题，相关术语也不懂
2. 用过一点但仍属小白：跟着用过，但不真正理解原理和结构
3. 已经入门，想进阶到资深：做过基础实践，想补系统设计、边界和工程化能力

你可以直接回复 1 / 2 / 3，也可以用自己的话描述目标读者。
```

## 教程型任务的进入条件

对“从 0 撰写 + 教程型”任务，进入正式调研前需要同时满足：

1. 用户已经确认默认调研模板，或提供自定义模板
2. 教程受众层级已经明确，或可由用户原话安全归类到 `1 / 2 / 3`

## 技术向任务的追加确认

如果当前主题明显偏开发、工程、架构，还要检查受众赛道是否明确。

如果不明确，必须追加下面这段确认话术：

```text
在开始调研前，我还需要确认这篇内容主要写给哪类读者：

1. 通用 AI 使用者：更偏普通用户、内容创作者、运营、产品初学者
2. 程序员 / 技术人员 / 架构师：更偏开发、工程、架构与技术实践

你可以直接回复 1 / 2，也可以用自己的话描述目标读者。
```

如果已经确认属于技术向，进入正式调研前还应尽量明确技术主题细分：

- `A` vibe coding / AI 编程经验
- `B` AI 开发工作流 / Agent 工作流
- `C` AI 工程实践
- `D` 框架 / SDK / 平台教程
- `E` 源码解析 / 调用链 / 关键模块拆解
- `F` 设计模式 / 架构设计 / 系统设计

## 技术向任务的进入条件

对“从 0 撰写 + 技术向”任务，进入正式调研前至少需要满足：

1. 用户已经确认默认调研模板，或提供自定义模板
2. 受众赛道已经明确，或可由用户原话安全归类到“通用向 / 技术向”

如果当前任务同时还是“教程型”，则还要继续满足教程受众层级已经明确。
