# 从 0 撰写模式

## 进入条件

用户只给了主题、背景、概要、平台、目标，或明确要求从 0 写一篇新稿。

## 正式调研前必须完成的事

### 1. 任务卡

至少补齐这 8 项：

- 主题：到底写什么
- 对象：写给谁
- 平台：公众号 / 小红书 / 知识星球 / PDF / 课程文档
- 目标：读者读完后得到什么
- 已知输入：用户已经给了什么
- 缺失输入：还缺什么
- 时效性：哪些内容容易变
- 必须补的调研问题：写前必须查清什么

### 2. 调研模板确认

必须先发送标准确认话术，等待用户确认默认模板或提供自定义模板。

未确认前：

- 不进入正式调研
- 不进入全文写作

## 确认后的默认调研顺序

1. 先看官方文档
2. 再看官方仓库、官方博客、作者资料
3. 再看高质量第三方教程
4. 最后看社区讨论

## 从 0 写作的输出顺序

1. 模式判断：从 0 撰写新稿
2. 文章类型判断
3. 任务卡
4. 调研稿或调研要点
5. 结构建议
6. 正式成稿

## 关键提醒

- 不要凭印象直接开写
- 先确定最值得写的角度，再组织材料
- 对时效性强的工具、版本、参数、命令，优先显式标注核验日期
