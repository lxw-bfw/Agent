# 从 0 模式的标准确认话术

当任务属于“从 0 撰写模式”时，在正式调研前必须先发送下面这段原话：

```text
我会按照《从0撰写模式下的标准调研输出模板.md》来完成调研。

如果您有自己的标准调研输出模板，可以在下面的对话中提供给我，我会按照你的调研模板来。

如果没有的话，你可以发送指令“没问题，开始工作吧”，在接下来的从0撰写文章的工作中，我将使用《从0撰写模式下的标准调研输出模板.md》作为默认的调研输出模板。
```

## 行为契约

只有在下面两种情况下，才进入正式调研：

1. 用户提供了自己的调研模板
2. 用户明确回复“没问题，开始工作吧”或等效确认

如果用户没有确认，就停在这里，不要越过这一步。
