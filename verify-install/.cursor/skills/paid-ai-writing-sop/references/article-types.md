# 文章类型路由

## 一、推荐型

适合场景：

- 工具推荐
- 仓库推荐
- 插件推荐
- 模型推荐
- 方案对比

核心问题：

- 哪个值得选
- 哪个适合谁
- 新手先从哪个开始

结构重点：

- 先给结论
- 给筛选标准
- 给速查表
- 给适合谁 / 不适合谁
- 给学习顺序或组合建议

## 二、教程型

适合场景：

- 安装教程
- 配置教程
- 接入教程
- 工作流搭建教程

核心问题：

- 怎么装
- 怎么配
- 怎么搭
- 怎么跑通

结构重点：

- 环境前提
- 最小闭环
- 步骤拆解
- 参数说明
- 排错与踩坑

## 三、方法论型

适合场景：

- Prompt 方法论
- Agent 使用框架
- 工具选择原则
- 常见误区与判断标准

核心问题：

- 为什么
- 怎么判断
- 常见误解是什么
- 正确框架是什么

结构重点：

- 先纠偏或先给结论
- 解释背景和底层逻辑
- 给判断框架
- 写适用边界和反例

## 四、如何快速分流

如果文章最终在卖：

- “知道该选什么” => 推荐型
- “知道怎么做” => 教程型
- “知道怎么判断” => 方法论型

如果一篇文章同时沾两类，优先按它最终售卖的主要价值判断，不按篇幅多少判断。
