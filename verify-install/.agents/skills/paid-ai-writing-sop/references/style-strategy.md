# 风格策略

## 主风格参考

### 歸藏

优先拿来做主结构骨架。

适合学：

- 开头先给判断
- 结构推进关系清楚
- 能把趋势、概念、工具、场景串起来
- 会主动写边界和限制

### 宝玉

优先拿来做解释层和教程层。

适合学：

- 抽象内容拆步骤
- 一段话只讲一个判断
- 先给任务，再给规则，再给样例
- 克制、专业、可复用

### 数字生命卡兹克

适合补标题和导语张力，不建议整篇全仿。

适合学：

- 开头抓力
- 场景切入
- 快速说明“这东西到底对谁有用”

## 写法红线

- 不要写成“AI 整理稿”口吻
- 不要全篇堆链接、堆功能点
- 不要只说“很强、很方便、很值得”
- 不要回避限制条件和失败场景

## 付费层质感来自哪里

- 结构更像老师，而不是资料搬运工
- 会先替读者做选择和排序
- 会主动指出误区、边界、适用人群
- 会交代时效性和核验日期
