# 工作流总览

## 目标

这套 SOP 不是普通润色流程，而是把任务升级为“付费级教程生产”。

固定目标包括：

1. 经过核验的正式正文
2. 资料来源清单
3. 版本与适用范围说明
4. 必要的误区纠偏与踩坑提醒

## 总流程

1. 先判断模式：改写 / 从 0
2. 模式不明确时先问用户
3. 再判断文章类型：推荐型 / 教程型 / 方法论型
4. 输出任务卡
5. 确认资料优先级和风格策略
6. 先出新结构，再进正文
7. 成稿强制补齐核验日期、误区、踩坑、边界、来源

## 资料优先级

1. 官方文档、官方仓库、官方博客、release note
2. 作者本人或维护者的一手表达
3. 高质量第三方教程
4. 社区讨论，仅作辅助

## 对正文的最低要求

- 讲清楚这篇文章到底卖什么
- 对新手有明确学习顺序或执行路径
- 对容易过时的内容给出核验日期和边界
- 不是只复述资料，而是形成判断和重组
